# Decisions

Engineering calls made without the owner, newest last. Each has a reason so it can be revisited.

| # | Date | Decision | Reason |
|---|---|---|---|
| 1 | 2026-11-14 | pnpm 10.34.6 (already on PATH), pinned via `packageManager`. | Available without any global install. |
| 2 | 2026-11-14 | TypeScript pinned to the newest 6.0.x, not 7.0.2 (npm `latest`). | `typescript-eslint` 8.72.2 declares `typescript >=4.8.4 <6.1.0`; TS 7 (the native port) is not supported by the lint toolchain yet. |
| 3 | 2026-11-14 | Pinned: three 0.187.0, @mediapipe/tasks-vision 1.2.3, @dimforge/rapier3d-compat 0.21.0, vite 8.3.8, vitest 5.1.0, eslint 10.15.0, @playwright/test 1.65.1. | Current stable on npm at kickoff; exact pins as required. |
| 4 | 2026-11-14 | MediaPipe WASM and `.task` models are **not committed**. `pnpm setup:assets` copies WASM from `node_modules` into `public/wasm/tasks-vision-<version>/` and downloads models (version `1` URLs, not `latest`) into `public/models/`. Both directories are gitignored. | About 35 MB of binaries would bloat git history; the script is deterministic and the paths are versioned for immutable caching. Deploys run the script before `pnpm build`. |
| 5 | 2026-11-14 | `Claude outputs/` (the kickoff brief) is gitignored, not committed and not modified. | It is the owner's planning file; its content now lives in `docs/`. Remove the ignore line to commit it. |
| 6 | 2026-11-14 | Custom subagent types (`builder`, `helper`, `reviewer`) were created in `.claude/agents/` but are not loadable until the session restarts, so tonight's subagents are general-purpose agents with the model set explicitly (sonnet, haiku, opus) and the role text in the prompt. | As instructed in the brief. |
| 7 | 2026-11-14 | The orchestrator writes the shared contract files (`src/tracking/types.ts`, `src/input/types.ts`, `src/core/sport.ts`) itself. They contain only type declarations and constants. | Interfaces must be decided by the orchestrator and committed before parallel builders start; writing them once as files is cheaper and more exact than repeating them in every brief. |
| 8 | 2026-11-14 | `noUncheckedIndexedAccess` is off. | The landmark path is typed-array index arithmetic; the flag would force `!` on every read with no safety gain. |
| 9 | 2026-11-14 | Landmark coordinates are mirrored once, in the tracking layer. Everything downstream (filters, recognizers, recordings, synthetic scripts) works in mirrored display space; landmark indices keep their anatomical meaning. The avatar is viewed from behind. | One convention, applied in one place; "player's left hand moves the on-screen left hand" then needs no further flips. |
| 10 | 2026-11-14 | One time base, "game ms". Camera frames are stamped from `requestVideoFrameCallback` metadata (`captureTime`, falling back to `presentationTime`), which is on the `performance.now()` timeline. Synthetic and replay sources are stepped by the game clock. | Camera-clock timestamps as required, directly comparable with game time for latency compensation, and `?timeScale` can speed up headless checks. |
| 11 | 2026-11-14 | Continuous signals (hand hold position, lean, knee-lift cadence) are exposed as in-place state on `InputProvider.state`; only discrete moments are events. | The brief lists `HandHold`, `Lean` and `KneeLiftCadence` as events, but emitting them every frame would allocate per frame. Same information, no garbage. |
| 12 | 2026-11-14 | Debug input (`?input=debug`) is a second `InputProvider` implementation, not a fake landmark source. | It must produce the same events and state the recognizers produce; skipping landmarks keeps it simple and deterministic. The synthetic player covers the landmark-to-recognizer path. |
| 13 | 2026-11-14 | `?renderer=webgl` selects `WebGPURenderer` with `forceWebGL: true` (its WebGL2 backend), not the legacy `WebGLRenderer`. | The legacy renderer needs the classic `three` build and classic materials; shipping both would duplicate three.js and every material. The switch still answers the real question (does the renderer contend with MediaPipe less on WebGPU or on WebGL2). |
| 14 | 2026-11-14 | Milestone 1 builders run in parallel in one working tree on disjoint directories, each checking only its own directory; the orchestrator runs the full checks before each commit. | Simpler than worktrees for four tasks with no shared files; contracts were committed first. |
| 15 | 2026-11-14 | Headless rounds are played by a per-sport bot (`Sport.createBot()`), not by fixed scripts. The shell asks the bot for the next moves whenever the synthetic player's move queue is empty. | A fixed script cannot react to game state (which hold is next, whether the pins have settled, how close the foul line is). The bot still goes through the full landmark, filter and recognizer path. |
| 16 | 2026-11-14 | Gesture events are queued and delivered in timestamp order from `InputProvider.update()`, once per rendered frame, never from inside a camera callback. | Sports get deterministic ordering inside the game loop. Costs at most one render frame of delay; each event still carries the true time of the moment. |
| 17 | 2026-11-14 | Throw, swing and punch recognizers measure wrist speed relative to the shoulder, and the throw recognizer suspends while the shoulders move faster than `maxBodySpeed`. | With image-space speed, a sidestep or squat looked like a 10 sw/s throw. |
| 18 | 2026-11-14 | Recognizer thresholds were retuned from the brief's starting points to fit the synthetic player after filtering (for example throw `minPeak` 2.5 sw/s, `startSpeed` 2.0, and a two-frame lag correction on peak times). All are placeholders until real recordings exist. | Filter lag attenuates peak speeds; the starting values never fired on soft throws. |
| 19 | 2026-11-14 | The device gate treats tracking as "sustains N Hz" when the tracker completes N back-to-back inferences per second on a synthetic frame (capped at 30), measured while a representative scene renders. | The gate runs before camera permission, so it cannot use the camera. |
| 20 | 2026-11-14 | `?short=1` plays a shortened round in every sport (two bowling frames, three pitches, two arrows, one javelin attempt, a 25 second climb). | Headless checks finish in reasonable time, and it is handy for quick tries. |
| 21 | 2026-11-14 | Climbing stamina drain was lowered from the first values (two hands 0.035 to 0.02 per second, one hand 0.06 to 0.035). | The bot ran out of stamina near 11 m, so the first rest ledge at 20 m was unreachable. To be judged by playtest. |
| 22 | 2026-11-14 | Bowling's default `hookGain` was lowered from 1.2 to 0.35. | The synthetic swing saturated the hook on every ball; real wrist-path curvature is unknown, and a ball that always hooks into the gutter would be a bad first impression. |
| 23 | 2026-11-14 | Javelin: crossing the foul line is called only after 0.45 s with no throw (`crossGraceS`), and a throw is back-dated to its release time. | Throw events arrive 170 to 300 ms after the wrist-speed peak; without the grace, a legal release just before the line was called a foul. |
| 24 | 2026-11-14 | Javelin's release angle is a proxy: the upward share of the wrist's 2D velocity at release, mapped onto 12 to 52 degrees. | The player throws into the screen, the axis the camera measures worst, so true loft is not observable. |
| 25 | 2026-11-14 | Batting judges a swing by the swing-start event's own timestamp plus `batTravelMs` (130), and resolves a pitch up to 250 ms after the ball has passed. | The tracker reports a swing late; judging by arrival time would make every swing late. This is the game's latency compensation. |
| 26 | 2026-11-14 | Archery has a fallback for players whose fist the tracker cannot see: auto-nock after 6 s with hands together, release on a quick move toward the bow hand or a 2.5 s hold. | Hand crops at distance are the least proven part of the pipeline; the sport should be playable on day one regardless. Bowling has an equivalent hold-still pick-up. |
| 27 | 2026-11-14 | The hand cursor is disabled for synthetic and replay sources, and for real players it cannot begin a dwell for 1.2 s after a screen appears or until the hand has been outside every button. | A hand resting where a button appears pressed "Play again" by itself. |
| 28 | 2026-11-14 | The production CSP is stricter than the starting point: no `blob:` anywhere, no inline styles. `vite preview` sends the same headers, so every Playwright suite runs under the production policy. | Each removal was proven by the browser suite passing with zero violations. |
| 29 | 2026-11-14 | Sports ran in parallel in one working tree with per-sport build directories and ports (`playwright.sport.config.ts`), not git worktrees. | Worktrees would each need their own `node_modules`, Chromium download and model files; disjoint directories gave the same isolation for free. |
| 30 | 2026-11-14 | Baseball batting's accent is lavender `#B8A6E6`; the pitcher is a second headless athlete in teal. | The brief gave accents for four venues; batting needed one. |
